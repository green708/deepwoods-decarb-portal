Bug Log — This Session

✓ Bug #1 FIXED — entity_scope_json always null in submissions (Critical)

src/routes/_app.submissions.tsx:554 — JSON.parse() called on an object (context.php auto-decodes JSON values from client_config). Parse always throws → entityScopeMap always null → scope filter never worked. Fix: check typeof raw === 'object' before parsing.

✓ Bug #2 FIXED — Wrong S3 categories key in GHG setup (Critical)

backend/api/ghg/setup-client.php:105 — looked for $sc['s3_boundary'] (doesn't exist in entity_scope_json). Correct key is $sc['s3_categories'] (integer array written by setup.tsx). Per-entity S3 scope was silently ignored. Fix: check s3_categories first, fall back to global s3_boundary.

✓ Bug #3 FIXED — submit.php missing active-client gate (Moderate)

backend/api/submit.php:10 — missing dolphin_require_active_client($authUser). An inactive client with a valid session token could upload data before Deepwoods activates their account. Fix: gate added after dolphin_require_auth().

✓ Bug #4 FIXED — decarb/assets.php hardcoded 'FL' (High, multi-tenant)

backend/api/decarb/assets.php:22 — $entity !== 'FL' bypasses entity filter for Featherlite consolidated. Any other client's consolidated entity would be incorrectly filtered. Fix: DB lookup for is_consolidated=1 entity code, matching the pattern in irec.php.

✓ Bug #5 FIXED — decarb/actions.php hardcoded 'FL' (High, multi-tenant)

backend/api/decarb/actions.php:22 — Same 'FL' consolidated bypass issue. Fix: same DB lookup pattern.
